# 0006. Embeddings locais multilíngues (multilingual-e5-small)

- Status: aceito
- Data: 2026-11-02

## Contexto
O sistema precisa de embeddings para textos em mais de um idioma.

## Opções consideradas
1. multilingual-e5-small, executado localmente (escolhida).
2. text-embedding-3-small, como adaptador alternativo.

## Decisão
Escolhemos o multilingual-e5-small local, mantendo o text-embedding-3-small como adaptador alternativo.
